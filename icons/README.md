# Icons Directory

## Cách tạo icons:

1. Mở file `icon-generator.html` trong trình duyệt
2. Nhấn nút "Tạo và Tải Xuống Tất Cả Icons"
3. Lưu tất cả file PNG vào thư mục này

## Kích thước cần thiết:

- icon-96x96.png
- icon-128x128.png
- icon-144x144.png
